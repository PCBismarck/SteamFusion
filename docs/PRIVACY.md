# 本地数据与源码发布

公开源码只包含程序、维护脚本、通用说明、应用图标和测试数据。测试中的账号、SteamID 和路径均为固定样例，不用于访问真实账号；SteamID 转换基数、AppID、Watt 商店应用标识和软件注册表路径属于程序常量。

程序运行时会在 `%LOCALAPPDATA%\SteamFusion` 保存本机工具路径、SteamID、登录用户名、显示昵称、游戏规则、库快照、状态和短时进程信号。沙盒可能保存 Steam 登录资料和游戏存档，日志和截图可能暴露账号信息；CSV/JSON 导出包含个人游玩记录。这些内容不属于源码交付。

仓库 `.gitignore` 排除构建产物、沙盒、备份、诊断、导出、运行配置和常见凭据文件。忽略规则不能保护已经跟踪的文件，也不能识别任意名称的新敏感文件。提交前检查 `git diff --cached` 和 `git ls-files`，不要把部署目录整体加入仓库。

发布包应由源码重新构建。不要上传使用过的安装目录、原始本机验证记录或来源不明的源码压缩包。分享问题复现时，将账号身份和私人路径替换为样例，并检查截图。
